# Holiday theme stylesheets

One file per theme, named `<key>.css` (keys in `src/utils/holidayTheme.js`). Every selector must
start with `[data-holiday="<key>"]` so the theme only applies while it is on. Logo variants go in
`src/assets/images/holidays/buzzard-<key>.png`. Full contract: `docs/handoffs/HOLIDAY_THEMES_HANDOFF.md`.
